# Zyte

zyte is a simple eso-lang I made, It's the first eso-lang I've made that actually uses an AST and Interpreter.

It revolves around registers and such, I was really tired so I just wrote a small 'showcase.zy' file where you can see how the syntax works.

It doesn't have normal arithmetical operations however it does have logical and conditional operations.

to run some code simply build the C# project, go to whichever directory you want and run the executable, it'll look for './code.zy', thats your code file.
